# **BFS-this-MESS**

## USER JOURNEY

A student registers for an account and specifies their initial state, including any subjects they have already completed. They create a road and set constraints, such as required subjects, subjects pinned to specific semesters, and semesters that should be locked. They then request possible paths, and the application computes and displays the shortest valid plans given their constraints. The student can compare the resulting paths and save a preferred one to revisit later. They can also share the road with an advisor, who can view its constraints and generated paths.
